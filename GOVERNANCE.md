# AIFP-2 Governance

AIFP-2 evolves through public, reviewable AIFP Improvement Proposals (AIPs).

## Decision principles

1. Protect payer funds and merchant entitlement before convenience.
2. Keep signing non-custodial and local by default.
3. Preserve interoperability without outsourcing the core protocol to one provider.
4. Make economics explicit and machine-verifiable.
5. Separate specification status from implementation and deployment status.
6. Fail closed when route identity, deployment evidence or verification is ambiguous.

Maintainers may merge editorial changes after review. Normative changes require at least one protocol maintainer and one independent security reviewer. Economic-profile changes require an explicit versioned decision and cannot be introduced through an implementation-only pull request.
